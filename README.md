# ABAP Portfólio - SAP S/4HANA

Exemplos práticos de desenvolvimento SAP ABAP S/4HANA desenvolvidos durante treinamento pela GPLUX.

## Sobre mim

Desenvolvedor ABAP Trainee/Júnior com foco em SAP S/4HANA. Cursando Ciência da Computação (5º semestre) e com experiência prática em projeto de migração Vistex no S/4HANA.

## Estrutura do Repositório

### 📁 CDS-Views
Exemplos de Core Data Services (CDS) no S/4HANA:
- CDS View Entity com annotations e OData
- CDS View Extend com lógica condicional
- CDS View com Associations e joins
- CDS Table Function com classe AMDP
- CDS View sobre tabelas Z customizadas (sistema de reservas de veículos)

### 📁 HANA
Exemplos de desenvolvimento com SAP HANA:
- SQL Nativo via ADBC (`cl_sql_statement`, `cl_sql_connection`)
- Relatório com tabelas Z customizadas usando agregações HANA

### 📁 Open-SQL
Exemplos de Open SQL moderno no S/4HANA:
- Open SQL com `CASE/WHEN`, `GROUP BY` e funções de agregação
- Cálculos matemáticos com `CAST` diretamente no SELECT

- ### 📁 OO

Exemplos de orientação a objetos em ABAP:

- Calculadora com encapsulamento, separação de responsabilidades e validação via domínio SAP (`DD07V`)

## Tecnologias
- SAP ABAP S/4HANA
- Core Data Services (CDS)
- SAP HANA / ADBC
- Open SQL moderno
- ABAP OO / AMDP
- SAP Fiori / OData
- Eclipse ADT
